strawberry-graphql/strawberryStrawberry GraphQL 0.320 → 0.322

0.320.0 adds GraphQL subscriptions over Server-Sent Events (opt-in, works with the FastAPI/ASGI integrations) and makes multipart subscriptions opt-in — a small breaking change if you rely on them. 0.321.0 adds schema-level exception handlers that map Python exceptions to typed GraphQL error unions, and 0.322.0 finally removes the long-deprecated Extension alias (import SchemaExtension instead).

stac-utils/stac-fastapi-pgstacstac-fastapi-pgstac 6.3.0

Adds the Multi-Tenant Catalogs Endpoint Extension for nested catalog support — useful if you ever need per-tenant STAC catalogs. Also a new neq query operator, more consistent settings handling via a config.Settings() class, and pgstac 0.8.6 deprecated in tests. 6.3.1 quickly fixed an optional-import bug from this release, so go straight to 6.3.1.

📎 6.3.0 release notes

hasura/graphql-engineHasura GraphQL Engine v2.49.4

Ops-relevant patch: websocket send queues are now bounded (HASURA_GRAPHQL_WEBSOCKET_QUEUE_SIZE, default 100, with new eviction metrics), fixing a slow-client memory pile-up. New extra_required_claims JWT option enforces that tokens actually contain the configured issuer/audience — worth a look if you verify Firebase or other third-party JWTs. The long-deprecated X-Hasura-Access-Key header was removed.

📎 v2.49.4 release notes

mapbox/mapbox-gl-jsMapbox GL JS v3.26.0

Published TypeScript declarations are now self-contained, fixing builds that failed with skipLibCheck: false. Also improves terrain raycast accuracy for mouse events and fixes a label bug on multilinestrings. Minor breaking change: transition/interpolated flags removed from the camera-projection style property.

overturemaps.orgOverture Maps 2026-06-17 release

microsoft/typescriptTypeScript 7.0

The native Go-port compiler is now the release line: 8–12x faster full builds, plus experimental parallelism flags (--checkers, --builders). Breaking defaults: strict: true is now the default, and AMD/UMD/SystemJS module output is gone. Expect the pnpm workspace upgrade to need some tsconfig attention.

📎 Announcing TypeScript 7.0

npmnpm 12 blocks postinstall scripts by default

Starting this month, npm v12 no longer runs package postinstall scripts by default — a big supply-chain-security shift after last year's worm incidents. pnpm has behaved this way since v10, so pnpm workspaces are unaffected, but CI images mixing npm could break.

TC39 / IETFES2026 approved; HTTP gets a QUERY method

Ecma formally approved ES2026, and the HTTP QUERY method (a safe, cacheable GET-with-body) is moving forward — genuinely useful someday for the kind of large geometry filters that currently get squeezed into POST bodies against OGC feature APIs.
