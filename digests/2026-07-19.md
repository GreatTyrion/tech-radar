# Tech digest — 2026-07-19

Window: 2026-06-19 → 2026-07-19 (first run, last 30 days).

## Your stack

### Strawberry GraphQL 0.320 → 0.322 — `strawberry-graphql/strawberry`
0.320.0 adds GraphQL subscriptions over Server-Sent Events (opt-in, works with the FastAPI/ASGI integrations) and makes multipart subscriptions opt-in — a small breaking change if you rely on them. 0.321.0 adds schema-level exception handlers that map Python exceptions to typed GraphQL error unions, and 0.322.0 finally removes the long-deprecated `Extension` alias (import `SchemaExtension` instead).
📎 [0.320.0 release notes](https://github.com/strawberry-graphql/strawberry/releases/tag/0.320.0)

### stac-fastapi-pgstac 6.3.0 — `stac-utils/stac-fastapi-pgstac`
Adds the Multi-Tenant Catalogs Endpoint Extension for nested catalog support — useful if you ever need per-tenant STAC catalogs. Also a new `neq` query operator, more consistent settings handling via a `config.Settings()` class, and pgstac 0.8.6 deprecated in tests. 6.3.1 quickly fixed an optional-import bug from this release, so go straight to 6.3.1.
📎 [6.3.0 release notes](https://github.com/stac-utils/stac-fastapi-pgstac/releases/tag/6.3.0)

### Hasura GraphQL Engine v2.49.4 — `hasura/graphql-engine`
Ops-relevant patch: websocket send queues are now bounded (`HASURA_GRAPHQL_WEBSOCKET_QUEUE_SIZE`, default 100, with new eviction metrics), fixing a slow-client memory pile-up. New `extra_required_claims` JWT option enforces that tokens actually contain the configured issuer/audience — worth a look if you verify Firebase or other third-party JWTs. The long-deprecated `X-Hasura-Access-Key` header was removed.
📎 [v2.49.4 release notes](https://github.com/hasura/graphql-engine/releases/tag/v2.49.4)

### Mapbox GL JS v3.26.0 — `mapbox/mapbox-gl-js`
Published TypeScript declarations are now self-contained, fixing builds that failed with `skipLibCheck: false`. Also improves terrain raycast accuracy for mouse events and fixes a label bug on multilinestrings. Minor breaking change: `transition`/`interpolated` flags removed from the `camera-projection` style property.
📎 [v3.26.0 release notes](https://github.com/mapbox/mapbox-gl-js/releases/tag/v3.26.0)

### Argo CD v3.5.0-rc2 — `argoproj/argo-cd`
The 3.5 release cycle is in RC. Notable fix already in the RC: auto-sync no longer gets skipped when a newer commit arrives mid-sync with `manifest-generate-paths` — a subtle drift-causing bug worth knowing about if you use that annotation. Stable branch got v3.4.5 as a routine patch.
📎 [v3.5.0-rc2 release notes](https://github.com/argoproj/argo-cd/releases/tag/v3.5.0-rc2)

## GIS world

### Overture Maps 2026-06-17 release — `overturemaps.org`
June data release (schema v1.17.0) refreshed the operating status of 8.5M US places using live member signals (Meta, TomTom, Uber). Schema heads-up: the `categories` property in places is deprecated and will be **removed in the September 2026 release**, replaced by `basic_category` + `taxonomy` — worth checking any queries that touch Overture places data. The foundation also hit 50 members in July.
📎 [Release notes](https://docs.overturemaps.org/blog/2026/06/17/release-notes/)

### PostgreSQL 19 Beta 2 + PostGIS 3.7 alpha — `postgresql.org`
PG 19 Beta 2 landed July 16 with GA expected ~September; PostGIS 3.7.0alpha1 is being built against it with updated GDAL/GEOS/PROJ. Migration note for later: `address_standardizer` and `postgis_tiger_geocoder` are being split out of core PostGIS into separate extensions.
📎 [Beta 2 announcement](https://www.postgresql.org/about/news/postgresql-19-beta-2-released-3350/)

## Worth knowing

### TypeScript 7.0 — `microsoft/typescript`
The native Go-port compiler is now the release line: 8–12x faster full builds, plus experimental parallelism flags (`--checkers`, `--builders`). Breaking defaults: `strict: true` is now the default, and AMD/UMD/SystemJS module output is gone. Expect the pnpm workspace upgrade to need some `tsconfig` attention.
📎 [Announcing TypeScript 7.0](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/)

### npm 12 blocks postinstall scripts by default — `npm`
Starting this month, npm v12 no longer runs package `postinstall` scripts by default — a big supply-chain-security shift after last year's worm incidents. pnpm has behaved this way since v10, so pnpm workspaces are unaffected, but CI images mixing npm could break.
📎 [LogRocket: Frontend Wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines)

### ES2026 approved; HTTP gets a QUERY method — `TC39 / IETF`
Ecma formally approved ES2026, and the HTTP QUERY method (a safe, cacheable GET-with-body) is moving forward — genuinely useful someday for the kind of large geometry filters that currently get squeezed into POST bodies against OGC feature APIs.
📎 [This Week in React #289](https://thisweekinreact.com/newsletter/289)
