# Tech digest — 2026-07-27

Window: 2026-07-19 → 2026-07-27.

A busy eight days: Ruff turned on 7x more rules by default, NISAR's radar archive opened to the public, and PostGIS 3.7 hit beta.

## Your stack

### Ruff 0.16.0 — `astral-sh/ruff`
The big one. Ruff now enables **413 rules by default, up from 59** — the first change to the default rule set since v0.1.0. Many of the newly-default rules catch real runtime errors rather than style nits, so expect a wave of new findings on first upgrade; pin your `select` list explicitly if you want the old behaviour. Also new: Ruff formats Python code blocks inside Markdown files (on by default), supports `# ruff: ignore[RULE]` comments alongside `noqa`, and `format --check` now emits `github`/`gitlab` annotation formats for CI.
📎 [Ruff v0.16.0 announcement](https://astral.sh/blog/ruff-v0.16.0)

### Prefect 3.8.0 — `PrefectHQ/prefect`
The V2 UI is now **the default for self-hosted servers** — the most visible change if you run your own Prefect instance. Under the hood there are several fixes worth having: server transactions now enforce READ COMMITTED isolation on PostgreSQL, duplicate server-minted flow-run state timestamps are gone, flow-run watch survives stream disconnects, and a lease-leak on cancelled acquires is fixed. Also `db_vacuum` no longer does a full scan of `event_resources` when a retention override is set.
📎 [3.8.0 release notes](https://github.com/PrefectHQ/prefect/releases/tag/3.8.0)

### TiTiler 2.1.0 → 2.2.0 — `developmentseed/titiler`
Two feature releases in a week. 2.1.0 migrates from `httpx` to **httpx2** and bumps Starlette to `>=1.0.1` — a dependency change to plan for rather than a drop-in patch. It also adds `minzoom`/`maxzoom` query parameters to the tileset endpoint, a `zooms` parameter to override WMTS zoom levels, and a `get-renders` method on the tiler factories. 2.2.0 adds PROJJSON headers and lets you control XML layer identifiers, plus a fix to `environment_dependency` handling in the cogeo extension.
📎 [2.2.0 release notes](https://github.com/developmentseed/titiler/releases/tag/2.2.0)

### tipg 1.5.0 — `developmentseed/tipg`
Small but operationally useful: an optional **Prometheus `/metrics` endpoint** with low-cardinality `operation` labels, so you can scrape per-operation stats without a metrics explosion. `/healthz` and `/metrics` are now excluded from Cache-Control headers. Handy if you run OGC Features APIs behind a monitored ingress.
📎 [1.5.0 changelog](https://github.com/developmentseed/tipg/blob/main/CHANGES.md)

### Mapbox GL JS v3.27.0 — `mapbox/mapbox-gl-js`
Upgraded to **TypeScript 7** internally — relevant if you're tracking the TS7 migration across your frontend deps. Fixes that matter in practice: the wrong access token being used in multi-map setups, a crash from `import.meta` under modern bundlers, broken dynamic imports in the UMD build, `number-format` dropping min/max fraction digits when set to 0, and missing buildings along tile borders. Also adds cross-source HD roads elevation for symbols.
📎 [v3.27.0 release notes](https://github.com/mapbox/mapbox-gl-js/releases/tag/v3.27.0)

### Strawberry GraphQL 0.323.0 — `strawberry-graphql/strawberry`
Adds an `on_stream_result` hook to `SchemaExtension`, letting extensions inspect or mutate results before they hit a streaming transport — it wraps subscription events plus queries/mutations sent over WebSockets, SSE or multipart, and each incremental-delivery frame where supported. The built-in `MaskErrors` extension now uses it, so **errors in streamed responses are finally masked** too, not just in plain request/response. Worth upgrading if you rely on `MaskErrors` and have subscriptions enabled.
📎 [0.323.0 release notes](https://github.com/strawberry-graphql/strawberry/releases/tag/0.323.0)

### uv 0.11.30 → 0.11.32 — `astral-sh/uv`
Three quick releases, mostly resolver performance (cached fork markers, faster lockfile serialization, cheaper cache decoding). Two things stand out: new `audit.malware-check` / `audit.malware-check-url` settings, and stricter validation that rejects source distributions and wheels whose package names don't match — both useful supply-chain guardrails. Workspace sources can now reference members in another workspace by path.
📎 [0.11.31 release notes](https://github.com/astral-sh/uv/releases/tag/0.11.31)

## GIS world

### PostGIS 3.7.0beta1 — `postgis.net`
First beta of the 3.7 line, released July 21 and built against PostgreSQL 19 Beta2 and GEOS 3.15.0beta2 (it still supports PG 14+). Notable: point-in-polygon fast paths for point-only GeometryCollections including `ST_Disjoint`, hash and merge join plans for `ST_OrderingEquals` joins, geometry/geography comparison functions marked leakproof, GML ArcString and curved polygon ring parsing, and `ST_AsRaster` accepting curved geometry. Also carries compatibility adjustments for GEOS 3.15's changed overlay line-merging behaviour — something to test for if you depend on overlay output shape.
📎 [PostGIS 3.7.0beta1 announcement](https://postgis.net/2026/07/PostGIS-3.7.0beta1/)

### Overture Maps 2026-07-22 release — `overturemaps.org`
Schema v1.18.0. Places gained three new top-level categories (arts and entertainment, lodging, cultural and historic landmarks) from expanded US coverage, with improved matching that cuts duplicates; the taxonomy now spans 12 top-level categories over ~70M entries. Transportation added ~957k TomTom segments (+10.7%), and Divisions is current with OSM through July 14. New this release: the pipeline records **provider category mappings**, so you can trace how a source's original category became an Overture one. Reminder that the deprecated places `categories` property is removed in the September release — two data drops left to migrate to `basic_category` + `taxonomy`.
📎 [2026-07-22 release notes](https://docs.overturemaps.org/blog/2026/07/22/release-notes/)

### NISAR L-band data goes public — `NASA Earthdata / ASF DAAC`
The NASA-ISRO SAR mission began its **first public release of calibrated L-band data on July 20**, covering observations from June 17 onward, with the mission's earlier first-year science data rolling out through the end of 2026. Products include geocoded single-look complex, unwrapped interferograms, polarimetric covariance and soil moisture, all in HDF5 and all free. Access via NASA Earthdata Search, ASF Vertex, the ASF APIs, or the `asf_search` Python package. If you work with SAR, this is a new global L-band archive at 12-day repeat worth evaluating alongside Sentinel-1.
📎 [NISAR L-band data released](https://www.earthdata.nasa.gov/news/nisar-l-band-data-released-expanding-record-surface-changes)

## Worth knowing

### React Compiler ported to Rust — `facebook/react`
Meta merged a Rust rewrite of the React Compiler into the React repo this month. It runs roughly 3x faster end-to-end (up to 10x on isolated transformation logic), and wiring it directly into Rust-based bundlers removes the Babel plugin hop — Turbopack reports over 40% faster compilation on real apps. Part of a broader move of frontend infrastructure into Rust (SWC, Oxc, Rspack). Notably, LLMs did much of the mechanical translation with humans on architecture and review, which has drawn some debate about long-term maintainability.
📎 [InfoQ: Meta ports React Compiler to Rust](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/)

Node shipped security updates on July 27 for all three active lines, with the highest severity rated **HIGH** on each. Worth patching build images and any Node-based services promptly; check the linked page for the CVE details now that the releases are out.
📎 [July 2026 security releases](https://nodejs.org/en/blog/vulnerability/july-2026-security-releases)
